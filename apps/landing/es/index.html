01 / LA INTENCIÓN

Más que un perfil.
Una historia compartida.

El cuidado ocurre por partes: una vacuna en la clínica, una nota de quien cuida a tu mascota, un recordatorio que llega justo a tiempo. Pettzi exploró cómo reunir esos fragmentos sin convertir el cuidado en papeleo.

El producto ya no está activo. El código sigue como proyecto de portafolio: permite explorar la arquitectura, las decisiones y el diseño de una aplicación full-stack real.

Leer el README del proyecto ↗
