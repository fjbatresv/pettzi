MAPA DEL SISTEMA / AWS CDK

Un producto, siete zonas conectadas

18 definiciones de stack · 8 API · 4 capas Lambda

CloudFront y S3 entregan la aplicación Angular y los recursos de correo; API Gateway enruta solicitudes a ocho API de dominio, cuyos handlers Lambda usan Cognito, una tabla DynamoDB compartida y el bucket S3 de documentos. EventBridge Scheduler invoca el flujo de recordatorios y cola, que envía correos con plantillas SES. Hay una capa de monitoreo definida; las clases AppRegistry existen, pero no están conectadas al punto de entrada CDK actual.

Leer el diagrama de arquitectura como una lista
  1. CloudFront sirve Angular desde un bucket S3 privado; FrontendStack configura certificado ACM y alias Route 53 cuando se proporciona un dominio propio.
  2. ApiDomainStack coloca una distribución CloudFront delante de ocho HTTP API de API Gateway y mapea sus prefijos; Cognito autoriza las rutas protegidas con JWT.
  3. Cada stack de API define handlers Lambda; las cuatro capas compartidas contienen dependencias SDK para Cognito, DynamoDB, S3 y SES.
  4. CoreInfraStack administra PettziTable y el bucket privado de documentos. GSI1 sirve para buscar mascotas por propietario, recordatorios de vacunas y registros compartidos por mascota.
  5. Los horarios de recordatorio invocan una Lambda de despacho, que encola el trabajo en SQS FIFO y llega a una Lambda consumidora que envía una plantilla SES.
  6. MonitoringStack define paneles y alarmas. Las clases AppRegistry existen en el código, pero no se crean desde el main.ts actual.

VISTA 01 / CONTEXTO

Las personas cuidadoras mantienen en contexto la salud de sus mascotas.

  1. Propietario principal o co-propietarioAdministra mascotas, eventos de salud, archivos, recordatorios y rutinas desde Angular.
  2. PettziConecta la experiencia web con API de dominio y registros compartidos.
  3. Destinatario de correoRecibe mensajes de cuenta y recordatorios enviados mediante plantillas SES.

VISTA 02 / CONTENEDORES

Una SPA, ocho API y servicios de datos compartidos.

  1. Contenedor webLa SPA Angular se aloja en S3 privado detrás de CloudFront.
  2. Contenedores APIOcho HTTP API de API Gateway enrutan a handlers Lambda en Node.js 24; Cognito autoriza rutas protegidas.
  3. Servicios compartidosDynamoDB, S3, SES, EventBridge Scheduler, SQS y cuatro capas Lambda apoyan a los dominios.

VISTA 03 / RUTA DE SOLICITUD

Una solicitud de evento cruza límites explícitos.

  1. Navegador → borde APIAngular envía la solicitud al dominio API; el prefijo la dirige al HTTP API de eventos.
  2. HTTP API → handlerEn una ruta protegida, el autorizador JWT de Cognito valida el token antes de invocar la Lambda de eventos.
  3. Handler → datosEl modelo de dominio mapea el evento con claves compartidas; el handler lee o escribe en PettziTable.
  4. Acceso a archivosUploads API devuelve URLs prefirmadas para transferir documentos o imágenes directamente a S3.

Algunas rutas son públicas, entre ellas las lecturas de catálogos y el acceso a registros compartidos.

VISTA 04 / ASÍNCRONO + CORREO

El recordatorio se entrega fuera de la solicitud API.

  1. Se guarda el recordatorioReminders API crea el recordatorio y su horario en EventBridge Scheduler.
  2. Se activa el horarioScheduler invoca la Lambda de despacho, que envía un mensaje a SQS FIFO.
  3. Se procesa el mensajeLa Lambda consumidora valida el recordatorio y usa la plantilla de recordatorio SES.
  4. Límite de rutinasLas lecturas y cambios de rutina usan Routines API; su stack no crea horarios.

05 / SIGUE EL RECORRIDO

De una intención
a un momento útil.

EVENTO DE SALUD

Registrar una visita en contexto

  1. 01 La persona registra una visita desde Angular.
  2. 02 La API de eventos valida la solicitud con su contrato.
  3. 03 Un servicio de dominio guarda el evento en DynamoDB.
  4. 04 La cronología lo muestra junto al historial de cuidado.

RECORDATORIO

Hacer llegar el seguimiento

  1. 01 La persona guarda un recordatorio de vacunación en Reminders API.
  2. 02 La API crea un horario único en EventBridge Scheduler.
  3. 03 Al llegar la fecha, Scheduler invoca una Lambda de despacho que encola el recordatorio en SQS FIFO.
  4. 04 Una Lambda consumidora valida el recordatorio y envía la plantilla SES.

06 / APUNTES DE INGENIERÍA

Decisiones con
sus bordes a la vista.

01 / DATOS

Una tabla en vez de varias

Alternativa: separar tablas por dominio. La tabla común reúne patrones documentados, a cambio de planificar claves e índices.

02 / LÍMITES

API de dominio con OpenAPI

Alternativa: acoplar servicios sin contratos documentados. Los contratos muestran límites y exigen mantener cada cambio alineado.

03 / CÓMPUTO

Servicios serverless de AWS

Alternativa: un servidor siempre activo. El escalado administrado reduce su operación, sujeto a límites del proveedor.

04 / ENTREGA

Handlers pequeños, lógica en dominio

Alternativa: reglas en cada handler. El dominio compartido da un flujo predecible, aunque añade una capa que recorrer.

05 / TAREAS PROGRAMADAS

EventBridge para recordatorios

Alternativa: buscar recordatorios pendientes en cada solicitud. La tarea programada queda aparte y entrega de forma asíncrona.

06 / HERRAMIENTAS

Monorepo Nx

Alternativa: repositorios separados. Nx comparte herramientas y requiere mantener explícitos los límites entre dominios.
